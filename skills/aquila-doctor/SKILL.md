# aquila-doctor

1. Run `npx aquila-ai doctor` and then `npx aquila-ai check`.
2. For each `✗` line, apply the fix the output itself suggests (usually `npx aquila-ai sync`,
   `npm i -D aquila-ai`, or the two `claude plugin …` commands for Claude Code).
3. Report the final state in 3–5 lines. Do not touch files without the "generated by aquila-ai" marker
   without asking.
